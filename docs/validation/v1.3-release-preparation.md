Before update, back up the database and KeePass configuration with KeePass closed. Install one plugin format (DLL or PLGX), reopen, and validate loading and settings. Roll back on plugin-load failure, configuration loss, or incorrect icon/database changes: close KeePass, replace the plugin with the saved v1.2.0 artifact, and restore the backed-up configuration and database if affected. Replacing the plugin alone does not undo icon changes. Downgrade recovery still requires host validation.
