## Publication and recovery contract

Publish only after all required evidence is green and the owner authorizes the concrete release. Upload the exact DLL, PLGX and checksum manifest validated here; a tag-triggered CI rebuild does not replace them. The build/tag workflow verifies artifacts with read-only permissions and does not publish a release automatically.

Before installation, close KeePass and back up the database and configuration. Use one plugin format. If loading, configuration preservation or icon behavior fails, close KeePass, restore the saved plugin and restore affected configuration/database backups. Plugin replacement alone cannot undo database icon changes. Record the observed recovery result before declaring rollback verified.

After authorized publication, verify the downloaded asset hashes against this record and the live GitHub Pages download links. Keep the stable website download on an existing release until the new release is actually available.
