`eng/smoke-site.ps1` saves screenshots, rendered DOM and results.json under a fresh ignored or temporary output directory. The DOM assertions reject mismatched viewport dimensions, image-load failures, document overflow and controls extending beyond the viewport; scrollable comparison tables are treated separately. It reads source as UTF-8, retains process handles, measures final content dimensions and calibrates platform window insets with fresh processes. Every attempt is retained; only exact-size successful renders count. Virtual screens use Chromium's [documented screen configuration](https://developer.chrome.com/docs/automation-and-testing/headless-screen-config).
