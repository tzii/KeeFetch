KeeFetch / Troubleshooting

Get back to fetching.

Resolve KeeFetch loading issues, missing icons, slow runs, TLS errors and diagnostic questions.

The plugin does not load

Check KeePass 2.x, .NET Framework 4.8 and the Plugins folder beside the running KeePass executable. Install only one copy of KeeFetch. Restart KeePass after replacement; PLGX compilation happens in the host. Record the full compilation error if loading fails.

An icon was not found

Check the entry URL, skip-existing-icons setting and selected profile. A site may have no usable image, block requests or expose formats that require a resolver fallback. A not-found result is possible even when the website opens in a browser.

A batch takes a long time

Slow or unreachable hosts can consume their request budgets. Try a smaller selection or Fast, and inspect provider timings. Managed profile budgets describe each entry's pipeline; they do not guarantee a batch duration.

Proxy or TLS problems

KeeFetch uses the system default proxy. Check connectivity and certificate errors. The private-host chain override is limited to recognized private/internal hosts; it cannot make an invalid public resolver certificate acceptable. Do not disable certificate checking globally.

Cancellation and retry

Cancel asks active work to stop. The v1.3 summary reports completed work and cancelled entries separately. Already applied icons remain. Retry Eligible offers one additional attempt for eligible misses/errors; skipped, invalid and cancelled entries are excluded. A second completion screen has no Retry action.

Find diagnostics

Use the paths shown in the completion screen. Logs are beside the database when possible, with a temporary-directory fallback. A long path can be copied from the summary. Review titles and URLs before sharing.

Report a reproducible bug

Include KeeFetch/KeePass versions, Windows version, plugin format, profile or Custom settings, expected versus actual behavior, and steps using a synthetic entry. For layout bugs include display scaling, theme and the affected form. Attach only redacted diagnostics and non-sensitive screenshots.
